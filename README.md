# Angel vs VC

Who this is for: founders choosing whether the first check should be an angel or a VC. How this was compiled: a fit table, not a ranking. Fundraising is super easy when the stage matches the check. Live matches: [investor match](https://roundfunded.com/en/tools/investor-match).

Last updated: 2026-09-02

Live investor names, counts, and matches are only on https://roundfunded.com/en/tools/investor-match. This repo is criteria and methodology, not the database.

## Problem

Pitching a VC who does not write pre-seed is a pass. Pitching an angel for a $4m round is also a pass.

## Fit

| Use an angel when | Use a VC when |
| --- | --- |
| First check, pre-seed or seed | You have a lead who will set a price |
| You want speed and a SAFE | You need a board seat, a pool, and a priced round |
| Check size is $10k to $250k | Check size is a fund check, not a personal wire |
| You can name why this person | You can name a partner who owns this sector |

Do not invent names of angels or VCs who will take the meeting.

## What this is not

- Not a scraped name list
- Not a fund and not an accelerator
- Not a claim of partnership with Y Combinator, Antler, Techstars, or 500 Global
